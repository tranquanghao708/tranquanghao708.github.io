Bình luận & cảm xúc

Dùng GitHub Discussions (Giscus) — public, mọi máy đều thấy.
• Sửa / xóa: đăng nhập GitHub → hover bình luận của bạn → Edit / Delete
• Gắn thẻ: gõ @username trong bình luận
• Reaction: dùng hàng cảm xúc của GitHub trên từng bình luận / discussion
• Link mục: copy ở khung phía trên rồi dán vào bình luận để trỏ đúng đoạn bài
