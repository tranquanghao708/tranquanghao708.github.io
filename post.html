Bình luận & cảm xúc

Dùng GitHub Discussions (Giscus) — public, mọi máy đều thấy được.
• Cần tài khoản GitHub để bình luận, trả lời và thả cảm xúc.
• Sửa / xóa bình luận của bạn: mở Discussions của repo, vào đúng bài bạn đã comment rồi Edit / Delete.
• Bạn không thể chỉnh sửa hay xóa bình luận của người khác.
• Term Giscus = tên file (?file=ten.md) hoặc tên thư mục (?post=ten-thu-muc). Title discussion cần chứa đúng chuỗi đó; category phải là General.
